## 🎯 Sobre o Evento

O primeiro evento do **AWS Student Builder Group da UEPB** foi estruturado para desmistificar a computação em nuvem para estudantes universitários, apresentando desde como acessar e estudar AWS de forma 100% gratuita até as melhores práticas essenciais de segurança e configuração de ambiente profissional.

### 📚 Principais Tópicos Abordados
1. **O que é Cloud Computing e o AWS SBG:** Os 3 pilares da comunidade (*Aprender, Construir e Conectar*).
2. **Como Estudar AWS de Graça:** AWS Skill Builder, Builder Labs sem necessidade de cartão de crédito e SimuLearn.
3. **Navegação no Console AWS:** Regiões globais, Zonas de Disponibilidade (AZs) e serviços essenciais.
4. **Segurança Fundamentada na AWS:**
   - O perigo de utilizar a conta *Root* no dia a dia.
   - Configuração de Multi-Factor Authentication (MFA).
   - Criação de usuários e grupos via AWS IAM seguindo o Princípio do Menor Privilégio.
   - Configuração de alertas de faturamento (*AWS Budgets* e CloudWatch Alarms).
5. **Integração AWS + VS Code:** Utilização segura do AWS Toolkit e AWS CLI sem expor credenciais em código.
