# 🔗 Links Úteis e Recursos Oficiais da AWS

Uma curadoria de recursos gratuitos e materiais recomendados pelo **AWS Student Builder Group - UEPB Campina Grande** para acelerar a jornada de aprendizado em computação em nuvem.

---

## 🎓 Plataformas Gratuitas de Estudo

| Recurso | Descrição | Link |
| :--- | :--- | :--- |
| **AWS Skill Builder** | Plataforma oficial da AWS com mais de 400 cursos gratuitos, desde fundamentos até tópicos avançados. | [Acessar](https://skillbuilder.aws/) |
| **AWS Builder Labs** | Mais de 10 laboratórios práticos gratuitos que rodam sem necessidade de cadastrar cartão de crédito. | [Acessar](https://skillbuilder.aws/learn) |
| **AWS SimuLearn** | Simulações interativas guiadas com cenários reais de tomada de decisão em arquitetura. | [Acessar](https://skillbuilder.aws/learn) |
| **AWS Cloud Quest** | Jogo no formato RPG 3D para aprender conceitos práticos de nuvem resolvendo desafios de clientes virtuais. | [Acessar](https://skillbuilder.aws/learn/FU5WCYVGKY) |
| **AWS Educate** | Programa voltado para estudantes com labs guiados e trilhas de aprendizado sem custo. | [Acessar](https://aws.amazon.com/education/awseducate/) |
| **Treinamentos via Twitch** | Aulas e lives semanais conduzidas por especialistas e Developer Advocates da AWS Brasil. | [Acessar](https://aws.amazon.com/pt/training/twitch/) |
